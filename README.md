# ゴルフスコア登録アプリ

初心者向けのゴルフスコア登録Webアプリ。ラウンド中は「打数＋パット数」だけを片手で入力でき、ホールごとの当日のピン位置（手前／中央／奥）をグリーン俯瞰図で確認できます。

[Claude Design](https://claude.ai/design) で作成したモックアップ（`Golf Score App.dc.html`）をもとに実装した、React + Vite のレスポンシブWebアプリです。

## 公開URL

https://lemontea-bit.github.io/golf/

`main` ブランチへの push で GitHub Actions が自動ビルド・デプロイします（`.github/workflows/deploy.yml`）。

## 画面構成

- **ホーム** — 進行中ラウンドのサマリー、平均スコア／ベスト／平均パットの統計、ゴルフ場検索への導線。右上のアバターをタップすると表示名を変更できます。
- **ラウンド** — テンキー式のスコア入力（打数1タップ＋パット数1タップ）。入力済みのホールは「この入力をクリア」で未入力に戻せます。
- **マップ** — ホールごとの当日のピン位置（手前／中央／奥）と距離
- **記録（スコアカード）** — 進行中ラウンドのスコアカード、パット数の内訳、過去ラウンドとのスコア推移、ラウンド履歴。履歴の各ラウンドは「編集」でコース名・日付・スコア・パー・パット数を修正、「削除」で削除できます。
- **ゴルフ場を探す** — 9件のサンプルコース（関東／関西／中部／九州／北海道）を、コース名・エリアでの検索、地域／条件チップによる絞り込み、料金での並び替えで探せます。コースをタップするとそのコースで進行中ラウンドを開始します（入力済みのスコアがある場合は確認ダイアログを表示）。

## データの扱い

バックエンドは無く、スコアやラウンド履歴は端末の `localStorage` に保存されます。初回起動時はデモ用のサンプルデータ（進行中ラウンドと過去3ラウンド）が入っていますが、実際に入力・保存したデータで自然に上書きされていきます。

## 開発

```bash
npm install

npm run build    # 本番ビルド
npm run preview  # ビルドのプレビュー

```

## 元デザインとの違い

- iOS実機の風防・ステータスバーなど、プロトタイプ特有の表示は省略し、レスポンシブなWebページとして実装しています。
- 「ラウンドを終了して履歴に保存する」ボタン（18ホール入力完了後にスコアカード画面に表示）は元デザインになかった追加機能です。ラウンドを実際に履歴へ確定させ、平均スコアやスコア推移をローカルデータから算出するために実装しました。
- ゴルフ場検索は入力テキスト・地域チップ・料金並び替えによる実際の絞り込みが動作し、コースを選ぶと進行中ラウンドに反映されます（元デザインは3件の静止データの見た目のみで、選択しても何も起きませんでした）。
- 表示名の変更、ラウンド履歴の編集・削除、ホール入力のクリアは元デザインになかった追加機能です。
